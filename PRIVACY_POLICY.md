# Teenagger Privacy Policy

*Last updated: August 25, 2026*

Teenagger ("the App") is a personal household tool used by a parent/guardian
to send chore reminders via SMS to their own family members, using Twilio's
messaging platform.

## What information we collect

The App stores only the information the parent/guardian enters directly into
its configuration:

- Phone numbers of the parent/guardian and their teenager(s)
- Names/labels associated with those phone numbers (e.g. "Alex")
- Chore descriptions, due times, and schedules
- A local log of message timestamps and delivery status, and whether a
  chore has been marked done

## How this information is used

This information is used **exclusively** to:

- Send scheduled SMS reminders ("nags") to the teenager(s) about assigned
  chores
- Detect and record a "done" reply from a teenager
- Notify the parent/guardian by SMS when a chore has been marked done

No information collected by the App is used for any other purpose.

## What we do not do

- We do not sell, rent, lease, or share any phone number, name, or message
  content with any third party.
- We do not use this data for advertising, marketing, profiling, or
  analytics of any kind.
- We do not share data with any party other than Twilio, Inc., which is
  used strictly as the SMS delivery infrastructure (the "processor") for
  sending and receiving the text messages described above. Twilio's own
  handling of message data is governed by
  [Twilio's Privacy Policy](https://www.twilio.com/en-us/legal/privacy).

## Where data is stored

All configuration and state data is stored locally, on the parent/guardian's
own computer, in a plain configuration file and a local state file. It is
not uploaded to any cloud service or third-party server by the App itself,
except as necessary to transmit the SMS messages via Twilio's API.

## Message frequency and opt-out

Message frequency depends on the chores and nagging schedule configured by
the parent/guardian. Any recipient can reply **STOP** at any time to opt out
of receiving further messages, consistent with standard SMS carrier
requirements. Reply **HELP** for assistance.

## Data retention and deletion

Data is retained only as long as the parent/guardian keeps it in the local
configuration and state files. Deleting the configuration file and/or state
file permanently removes the stored phone numbers, chore data, and message
history from the App.

## Changes to this policy

If this policy changes, the updated version will be posted at the same
location and the "Last updated" date above will be revised accordingly.
